What is an array?
-An array is a collection of elements of 
the same type stored in contiguous memory 
locations.

-It is the type of Non-Primitive Data Structure,specifically
a linear data Structure where data are stored in sequential
approach.   

-SYNTAX:
 datatype array_name[size];

lets look at the following example:
int arr[5] = {1, 2, 3, 4, 5};
here,int is the integer data type,arr is the name of
array and 5 is its size,this is example of predifined or
simply initiated array,where the value to be stored is 
already initiated.whereas,If you declared int arr[5]; without
the {…},the array would be uninitialized,

Key Points:

-Elements are indexed from 0.
-Size must be constant in C(unless using dynamic memory).
-Arrays are linear data structures.
-Can be 1D,2D,or multi-dimensional.
